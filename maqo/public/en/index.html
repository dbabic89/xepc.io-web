First launch

Android

  1. Download Maqo-—.apk and open the file.
  2. When Android asks, allow the browser to install unknown apps, then return to the installation.
  3. Start Maqo and sign in with your account.
System requirements: Android 8 ili novije

macOS

  1. Open Maqo-—.dmg and drag Maqo into the Applications folder.
  2. The first time: System Settings → Privacy & Security → “Open Anyway”.
  3. Start Maqo and sign in with your account.
System requirements: macOS 12 ili novije

Windows

  1. Run Maqo-—.msi. Administrator rights are not required.
  2. If the blue SmartScreen window appears: “More info” → “Run anyway”.
  3. Start Maqo from the Start menu and sign in.
System requirements: Windows 10 ili novije
